
El **Anclaje** es un sesgo cognitivo poderoso según el cual **las personas dependen excesivamente de la primera información que reciben** (el “ancla”) a la hora de tomar decisiones posteriores.

Una vez que se establece un ancla, los juicios siguientes (precio, valor, probabilidad, calidad, etc.) se ajustan a partir de ese punto de referencia, aunque el ancla sea arbitraria o poco relevante.

---

### 1. Principio psicológico fundamental

| Concepto                        | Descripción |
|---------------------------------|-------------|
| **Anclaje**                     | La primera información condiciona todas las evaluaciones posteriores |
| **Punto de referencia**         | El ancla se convierte en la base sobre la cual se juzga todo lo demás |
| **Ajuste insuficiente**         | Las personas se mueven desde el ancla, pero no lo suficiente |
| **Ancla arbitraria**            | Incluso números aleatorios pueden influir en juicios posteriores |
| **Ancla relevante**             | Cuando el ancla tiene sentido contextual, su poder aumenta |
| **Primacía de la información**  | Lo primero que se presenta tiene más peso del que debería |
| **Contraste anclado**           | El valor percibido de algo cambia según con qué se compare |

---

### 2. Tipos de Anclaje

| Tipo de Anclaje                 | Descripción | Ejemplo | Nivel de poder |
|---------------------------------|-------------|---------|----------------|
| **Anclaje de precio**           | Mostrar un precio alto primero | “Antes $997 → ahora $297” | Extremadamente Alto |
| **Anclaje numérico**            | Cualquier número inicial influye en estimaciones | “¿Cuánto pagarías? La mayoría dice más de 500” | Muy Alto |
| **Anclaje de comparación**      | Presentar una opción cara para hacer otra más atractiva | Plan Premium vs Plan Básico | Muy Alto |
| **Anclaje de valor**            | Mostrar el valor total antes del precio | “Valor total $2.800 → inviertes solo $397” | Extremadamente Alto |
| **Anclaje de cantidad / tamaño**| Establecer una cantidad de referencia | “Normalmente se entregan 12 módulos… aquí tienes 27” | Alto |
| **Anclaje de tiempo**           | Usar plazos o duraciones como referencia | “Esto normalmente toma 18 meses… lo haremos en 90 días” | Alto |
| **Anclaje social**              | Usar lo que otros pagan o hacen como referencia | “La mayoría de empresas invierte entre $5k y $15k” | Alto |
| **Anclaje de autoridad**        | Usar la opinión de un experto como punto de partida | “Según los principales analistas, el valor está en…” | Alto |
| **Anclaje de expectativa**      | Crear una expectativa alta o baja de antemano | “Esto no es barato… pero tampoco es lo que estás pensando” | Muy Alto |
| **Anclaje negativo**            | Usar un ancla desfavorable para luego mejorar la percepción | Mostrar el problema costoso primero | Alto |
| **Anclaje múltiple**            | Varios anclas secuenciales que empujan en la misma dirección | Valor + precio tachado + comparación + prueba social | Máximo |

---

### 3. Técnicas de Anclaje más efectivas

| Técnica                         | Cómo funciona | Ejemplo práctico |
|---------------------------------|---------------|------------------|
| **Precio tachado / Before-After** | Mostrar el precio original alto y luego el actual | “$1.497 $497” |
| **Valor acumulado**             | Sumar el valor de todo lo incluido y luego revelar el precio | “Valor total $3.200 → hoy $397” |
| **Opción señuelo (Decoy)**      | Introducir una opción intermedia o inferior para empujar a la deseada | Plan A, Plan B (señuelo), Plan C |
| **Anclaje alto + concesión**    | Empezar muy alto y luego bajar | Negociación clásica |
| **Precio de referencia externo**| Usar precios de mercado o de competidores | “En el mercado esto cuesta entre $2k y $5k” |
| **Anclaje de resultado**        | Anclar al beneficio económico o de tiempo | “Esto puede generarte $10k extra… la inversión es $1k” |
| **Anclaje de escasez + precio** | Combinar precio alto de referencia con limitación | “Precio normal $997 · solo 15 plazas a $397” |
| **Anclaje de identidad / nivel**| Asociar el precio a un nivel de persona | “Esto es lo que invierten los que van en serio” |
| **Anclaje secuencial**          | Ir revelando anclas de mayor a menor impacto | Valor → comparación → precio tachado → precio final |
| **Anclaje de esfuerzo o tiempo**| Comparar con el coste de no hacerlo o de hacerlo solo | “Hacerlo por tu cuenta te tomaría 12 meses” |

---

### 4. Anclaje en Pricing (una de las aplicaciones más potentes)

| Estrategia de Pricing con Anclaje | Descripción | Efecto principal |
|-----------------------------------|-------------|------------------|
| **Precio de anclaje alto**         | Mostrar primero la versión más cara | Hace que las demás parezcan razonables |
| **Anclaje de valor percibido**    | Enfatizar todo lo que se recibe | Justifica el precio |
| **Charm pricing anclado**         | $497 se siente mucho más bajo después de $997 | Contraste |
| **Precio por comparación**        | “Menos de lo que gastas en café al mes” | Minimiza la percepción de coste |
| **Anclaje de ROI**                | “Invierte $X y recupera $Y” | Cambia el marco de evaluación |
| **Good-Better-Best**              | Tres opciones donde la del medio o la alta se benefician del ancla | Empuja hacia la opción objetivo |
| **Anclaje de descuento**          | El descuento se percibe desde el precio ancla | Aumenta la sensación de ganga |

### 5. Aplicaciones prácticas por contexto

| Contexto                        | Cómo se usa el Anclaje |
|---------------------------------|------------------------|
| **Sales Pages / VSLs**          | Valor total → precio tachado → precio final |
| **Negociación**                 | Oferta inicial alta o baja según el objetivo |
| **Pricing pages**               | Planes ordenados para anclar la percepción |
| **E-commerce**                  | Precio original tachado + descuento |
| **High-Ticket**                 | Anclar al valor del resultado o al coste de la inacción |
| **Propuestas comerciales**      | Mostrar primero el alcance completo y luego el precio |
| **Fundraising**                 | Anclar la valoración con comparables o tracción |
| **Copywriting**                 | Anclar expectativas antes de revelar la oferta |
| **Psicología de precios**       | Hacer que un precio parezca bajo o justo por contraste |
| **Diseño de ofertas**           | Bonos y valor acumulado como ancla |

---

### 6. Factores que aumentan el poder del Anclaje

| Factor                          | Efecto |
|---------------------------------|--------|
| **Primacía**                    | Cuanto más al inicio aparezca el ancla, más fuerte |
| **Credibilidad del ancla**      | Un ancla creíble pesa más que una arbitraria |
| **Contraste claro**             | La diferencia entre el ancla y el precio final debe ser evidente |
| **Especificidad**               | Números exactos suelen anclar mejor que redondos en ciertos contextos |
| **Repetición del ancla**        | Mencionar el valor/precio de referencia varias veces |
| **Contexto emocional**          | Cuando hay incertidumbre, el ancla influye más |
| **Visualización**               | Precios tachados, tablas de valor, comparativas visuales |
| **Aislamiento del ancla**       | Evitar que otras referencias compitan demasiado pronto |

---

### 7. Combinación con otros triggers psicológicos

| Trigger                         | Cómo se potencia con Anclaje |
|---------------------------------|------------------------------|
| **Escasez / Urgencia**          | “Precio normal $997 → solo hoy $397” |
| **Prueba Social**               | “La mayoría paga $X… tú puedes acceder por menos” |
| **Autoridad**                   | “Según expertos / el mercado, el valor está en…” |
| **Aversión a la pérdida**       | Anclar al coste de no actuar |
| **Reciprocidad**                | Después de dar valor, el precio anclado se percibe más justo |
| **Identidad**                   | “Esto es lo que invierten las personas de este nivel” |
| **Esperanza de Transformación** | Anclar al valor de la vida/resultados futuros |

---

### 8. Errores comunes al usar Anclaje

| Error                           | Por qué falla o genera rechazo |
|---------------------------------|--------------------------------|
| Ancla demasiado irreal          | Se percibe como manipulación |
| No justificar el precio/valor de referencia | Pierde credibilidad |
| Mostrar el precio bajo demasiado pronto | Se pierde el efecto de contraste |
| Usar anclas confusas o múltiples contradictorias | Genera desorden mental |
| No adaptar el ancla al público  | Un ancla alta puede asustar a un segmento sensible al precio |
| Abusar del precio tachado falso | Destruye confianza a largo plazo |
| Olvidar el ancla de valor (solo enfocar en precio) | Se compite solo por ser barato |
| No probar diferentes anclas     | Se deja valor sobre la mesa |

### 9. Niveles de sofisticación

| Nivel                           | Características | Ejemplo |
|---------------------------------|-----------------|---------|
| **Básico**                      | Precio tachado simple | “$997 $497” |
| **Intermedio**                  | Valor acumulado + precio tachado | Lista de bonos + total + precio final |
| **Avanzado**                    | Anclaje múltiple (valor + comparación + ROI + escasez) | Sistema completo de percepción de valor |
| **Élite**                       | Anclaje narrativo + identitario + de resultado | El precio se siente inevitablemente justo o incluso bajo |

---

### 10. Señales de que el Anclaje está funcionando

- El precio final se percibe como “razonable” o “una ganga”
- Las objeciones de precio disminuyen
- La gente comenta el descuento o el valor más que el precio absoluto
- Se elige más la opción que tú querías empujar (en menús de precios)
- El cliente usa el ancla en su propio razonamiento (“si normalmente vale X…”)
- Aumenta la disposición a pagar
- Se reduce la comparación con alternativas más baratas e irrelevantes
