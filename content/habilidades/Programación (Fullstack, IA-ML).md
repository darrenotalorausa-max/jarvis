
La **Programación** es la habilidad de dar instrucciones precisas a una computadora para que ejecute tareas.  
En el contexto actual se divide principalmente en dos grandes ramas de alto valor:

- **Fullstack Development** → Construir aplicaciones web/mobile completas.
- **IA / Machine Learning** → Construir sistemas que aprenden de datos y toman decisiones.

---

### 1. Pilares fundamentales de la Programación

| Pilar                          | Descripción | Importancia |
|--------------------------------|-------------|-----------|
| **Lógica de programación**     | Pensar en algoritmos y flujos | Base de todo |
| **Estructuras de datos**       | Arrays, listas, árboles, grafos, hashmaps… | Eficiencia |
| **Algoritmos**                 | Ordenamiento, búsqueda, recursión, etc. | Resolución de problemas |
| **Paradigmas**                 | Imperativo, Orientado a Objetos, Funcional, Reactivo | Flexibilidad mental |
| **Complejidad (Big O)**        | Entender eficiencia de tiempo y espacio | Escalabilidad |
| **Debugging**                  | Encontrar y corregir errores | Productividad real |
| **Control de versiones**       | Git y flujos de trabajo | Trabajo profesional |
| **Testing**                    | Unit, integration, e2e | Calidad y confianza |

### 4. Stack moderno recomendado (2025-2026)

**Fullstack clásico + moderno:**
- Frontend: TypeScript + React / Next.js + Tailwind + shadcn/ui
- Backend: TypeScript (Node) o Python (FastAPI)
- Base de datos: PostgreSQL + Prisma / Drizzle
- Auth: Clerk / Supabase Auth
- Deploy: Vercel + Railway / Render

**IA / ML aplicado:**
- Python + PyTorch
- LangChain / LangGraph o LlamaIndex
- Vector DB (pgvector o Pinecone)
- OpenAI / Claude / Gemini / modelos open-source
- n8n o Make para automatizaciones + agentes

### 5. Niveles de dominio en Programación

| Nivel                          | Capacidad principal | Resultado típico |
|--------------------------------|---------------------|------------------|
| **Principiante**               | Sintaxis y lógica básica | Scripts simples |
| **Junior**                     | Construye features con supervisión | Contribuye a proyectos |

| **Senior**                     | Diseña sistemas y toma decisiones técnicas | Liderazgo técnico |

| **AI Engineer / Specialist**   | Diseña y despliega sistemas de IA | Productos con inteligencia |
