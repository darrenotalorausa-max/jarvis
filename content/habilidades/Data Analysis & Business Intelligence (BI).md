
**Data Analysis** es el proceso de inspeccionar, limpiar, transformar y modelar datos para descubrir información útil, llegar a conclusiones y apoyar la toma de decisiones.  

**Business Intelligence (BI)** es el conjunto de estrategias, procesos, tecnologías y herramientas que convierten datos en información accionable para el negocio.

Juntos forman una de las habilidades más demandadas y de mayor impacto en cualquier organización moderna.

---

### 1. Diferencia entre Data Analysis y Business Intelligence

| Concepto                      | Enfoque principal                      | Orientación          | Ejemplo de salida |
|-------------------------------|----------------------------------------|----------------------|-------------------|
| **Data Analysis**             | Explorar y entender los datos          | Analítica y descubrimiento | Insights, modelos, pruebas de hipótesis |
| **Business Intelligence**     | Monitorear y reportar el rendimiento   | Operativa y estratégica | Dashboards, KPIs, reportes |
| **Data Science**              | Predecir y optimizar con modelos avanzados | Predictiva y prescriptiva | Modelos de ML, forecasts |
| **Analytics Engineering**     | Preparar datos confiables para análisis | Infraestructura de datos | Modelos de datos limpios y documentados |

### 2. Ciclo completo del análisis de datos

| Etapa                         | Qué se hace                            | Herramientas comunes |
|-------------------------------|----------------------------------------|----------------------|
| **1. Pregunta de negocio**    | Definir qué se quiere responder        | Reuniones, frameworks |
| **2. Recolección de datos**   | Obtener datos de distintas fuentes     | SQL, APIs, extracciones |
| **3. Limpieza y preparación** | Corregir errores, nulos, duplicados    | SQL, Python, dbt |
| **4. Exploración (EDA)**      | Entender patrones y anomalías          | Python, R, Excel, Tableau |
| **5. Análisis / Modelado**    | Aplicar técnicas analíticas            | SQL, Python, R, herramientas BI |
| **6. Visualización**          | Comunicar hallazgos de forma clara     | Tableau, Power BI, Looker, Matplotlib |
| **7. Interpretación**         | Traducir datos a recomendaciones       | Pensamiento de negocio |
| **8. Acción y seguimiento**   | Implementar y medir el impacto         | Dashboards y alertas |

### 3. Tipos de análisis de datos

| Tipo de análisis              | Pregunta que responde                  | Complejidad | Ejemplo |
|-------------------------------|----------------------------------------|-------------|---------|
| **Descriptivo**               | ¿Qué pasó?                             | Baja        | Ventas del mes pasado |
| **Diagnóstico**               | ¿Por qué pasó?                         | Media       | Por qué bajaron las conversiones |
| **Predictivo**                | ¿Qué es probable que pase?             | Alta        | Forecast de demanda |
| **Prescriptivo**              | ¿Qué deberíamos hacer?                 | Muy Alta    | Optimización de precios o inventario |
| **Cognitivo / Avanzado**      | Sistemas que aprenden y recomiendan    | Muy Alta    | Recomendadores y detección de anomalías |

### 6. Conceptos clave de Business Intelligence

| Concepto                      | Qué es |
|-------------------------------|--------|
| **KPI**                       | Indicador clave de rendimiento |
| **Métrica vs Dimensión**      | Lo que se mide vs cómo se parte |
| **Dashboard**                 | Vista visual de métricas clave |
| **Scorecard**                 | Seguimiento de objetivos |
| **Data Warehouse**            | Repositorio central de datos analíticos |
| **Data Lake / Lakehouse**     | Almacenamiento más flexible de datos crudos y procesados |
| **Single Source of Truth**    | Una única fuente confiable de datos |
| **Self-Service BI**           | Que el negocio pueda analizar sin depender siempre del analista |
| **Semantic Layer**            | Capa de métricas y definiciones de negocio |
| **Real-time vs Batch**        | Datos en tiempo real o procesados por lotes |
| **Data Governance**           | Calidad, seguridad, ownership y documentación de los datos |

### 9. Habilidades complementarias de alto valor

- Pensamiento crítico y formulación de preguntas
- Comunicación clara de insights (storytelling con datos)
- Conocimiento del negocio (unit economics, funnels, LTV, CAC…)
- Estadística aplicada
- Productividad con SQL y Python
- Diseño de visualizaciones efectivas (evitar chart junk)
- Documentación y reproducibilidad
- Colaboración con equipos técnicos y de negocio
- Criterio para decidir qué medir y qué no

---

### 10. Errores comunes en Data Analysis / BI

- Analizar sin una pregunta de negocio clara
- Usar datos de mala calidad sin limpiarlos
- Confundir correlación con causalidad
- Crear demasiados dashboards que nadie usa
- No definir métricas de forma consistente
- Visualizaciones confusas o engañosas
- Reportar números sin contexto ni recomendación
- Depender solo de herramientas sin entender los datos
- No documentar transformaciones ni definiciones
- Ignorar el factor humano (adopción y cultura de datos)
