
**SEO (Search Engine Optimization)** es el conjunto de técnicas y estrategias para mejorar la visibilidad y el posicionamiento de un sitio web en los resultados orgánicos de buscadores (principalmente Google).  

**ASO (App Store Optimization)** es el equivalente para aplicaciones móviles: optimizar la visibilidad y conversión de una app dentro de las tiendas (App Store de Apple y Google Play).

Ambos buscan lo mismo: **atraer tráfico cualificado de forma orgánica y sostenible**.

---

### 1. Diferencia entre SEO y ASO

| Aspecto                        | SEO                                      | ASO                                      |
|--------------------------------|------------------------------------------|------------------------------------------|
| **Dónde se optimiza**          | Sitios web y contenido                   | Fichas de aplicaciones móviles           |
| **Plataformas principales**    | Google, Bing, YouTube, etc.              | Apple App Store y Google Play            |
| **Objetivo**                   | Tráfico orgánico y conversiones web      | Descargas e instalaciones orgánicas      |
| **Factores clave**             | Contenido, autoridad, técnica, UX        | Título, keywords, creatividades, ratings |
| **Ciclo de actualización**     | Continuo                                 | Continuo + dependencia de releases       |
| **Métricas principales**       | Posiciones, tráfico, CTR, conversiones   | Impresiones, conversiones a instalación, rankings |

### 2. Pilares del SEO

| Pilar                          | Qué incluye                              | Importancia |
|--------------------------------|------------------------------------------|-----------|
| **SEO Técnico**                | Cómo rastrea e indexa el buscador        | Crítica |
| **SEO On-Page**                | Optimización dentro de la página         | Muy Alta |
| **SEO Off-Page**               | Señales externas (enlaces y menciones)   | Muy Alta |
| **Contenido**                  | Calidad, relevancia y profundidad        | Crítica |
| **Experiencia de usuario (UX)**| Velocidad, usabilidad, mobile-first      | Muy Alta |
| **E-E-A-T / Confianza**        | Experiencia, Expertise, Autoridad y Confianza | Alta (especialmente YMYL) |
| **Intent Matching**            | Alinear contenido con la intención de búsqueda | Crítica |

### 3. SEO Técnico – Elementos clave

| Elemento                       | Qué es / Para qué sirve |
|--------------------------------|-------------------------|
| **Crawlability**               | Que Google pueda rastrear el sitio |
| **Indexación**                 | Que las páginas importantes estén en el índice |
| **Arquitectura web**           | Estructura clara y jerárquica |
| **Velocidad / Core Web Vitals**| LCP, INP, CLS |
| **Mobile-First**               | Diseño y rendimiento en móvil |
| **HTTPS / Seguridad**          | Certificado SSL |
| **Datos estructurados (Schema)**| Rich results y mejor comprensión |
| **XML Sitemap**                | Ayuda a descubrir URLs |
| **Robots.txt**                 | Control de rastreo |
| **Canonicalización**           | Evitar contenido duplicado |
| **Hreflang**                   | Sitios multi-idioma / multi-país |
| **Log analysis**               | Entender cómo rastrea Google de verdad |
| **JavaScript SEO**             | Asegurar que el contenido se indexe correctamente |
| **Internacional SEO**          | Estrategias multi-país y multi-idioma |

### 4. SEO On-Page – Elementos clave

| Elemento                       | Qué optimizar |
|--------------------------------|---------------|
| **Title Tags**                 | Titulares orientados a CTR y keywords |
| **Meta Descriptions**          | Descripciones que generen clics |
| **Headings (H1–H6)**           | Estructura semántica del contenido |
| **URL structure**              | URLs limpias y descriptivas |
| **Contenido**                  | Relevancia, profundidad, originalidad |
| **Internal Linking**           | Enlazado interno estratégico |
| **Imágenes**                   | Alt text, peso, formatos modernos (WebP/AVIF) |
| **Keyword Placement**          | Uso natural de palabras clave |
| **Thin / Duplicate Content**   | Evitar contenido pobre o duplicado |
| **Page Experience**            | UX + velocidad + estabilidad visual |
| **CTA y conversión**           | Que el tráfico se convierta |

### 6. Tipos de SEO según enfoque

| Tipo                           | Descripción | Ejemplo |
|--------------------------------|-------------|---------|
| **SEO de contenidos / Editorial** | Posicionar artículos y guías | Blogs, medios, SaaS content |
| **SEO de producto / E-commerce** | Categorías, fichas y filtros | Tiendas online |
| **SEO Local**                  | Búsquedas con intención local | Google Business Profile, NAP |
| **SEO Internacional**          | Varios países e idiomas | Hreflang + arquitectura |
| **Programmatic SEO**           | Páginas generadas a escala | Marketplaces, directorios |
| **SEO para SaaS**              | Features, comparativas, use cases | Product-led content |
| **YouTube SEO**                | Optimización de videos | Títulos, thumbnails, retención |
| **Image SEO**                  | Posicionamiento en Google Imágenes | Alt, nombre de archivo, contexto |
| **News / Discover SEO**        | Visibilidad en Google News y Discover | Actualidad y E-E-A-T |
| **Technical SEO Specialist**   | Enfoque profundo en arquitectura y rastreo | Sitios grandes y complejos |

### 7. ASO – App Store Optimization

#### Elementos principales de ASO

| Elemento                       | Apple App Store | Google Play | Impacto |
|--------------------------------|-----------------|-------------|---------|
| **Título de la app**           | Sí (limitado)   | Sí          | Muy Alto |
| **Subtítulo / Short description** | Sí            | Sí          | Alto |
| **Keyword field**              | Sí (100 caracteres) | No (se extrae del texto) | Muy Alto en iOS |
| **Descripción larga**          | Sí              | Sí          | Medio-Alto |
| **Icono**                      | Sí              | Sí          | Muy Alto (conversión) |
| **Screenshots**                | Sí              | Sí          | Muy Alto |
| **Preview video**              | Sí              | Sí          | Alto |
| **Ratings & Reviews**          | Sí              | Sí          | Muy Alto |
| **Categoría y subcategoría**   | Sí              | Sí          | Medio |
| **Localización (idiomas)**     | Sí              | Sí          | Alto |
| **Frecuencia de actualizaciones** | Indirecto    | Indirecto   | Medio |
| **Conversion Rate (CR)**       | Crítico         | Crítico     | Crítico |

### 9. Métricas clave de SEO y ASO

#### SEO
| Métrica                        | Qué mide |
|--------------------------------|----------|
| **Posiciones (Rankings)**      | Lugar en los resultados |
| **Tráfico orgánico**           | Visitas provenientes de búsqueda |
| **CTR orgánico**               | Clics / impresiones |
| **Impressions**                | Veces que se muestra el sitio |
| **Core Web Vitals**            | Rendimiento y experiencia |
| **Domain Authority / Rating**  | Autoridad estimada del dominio |
| **Backlinks y referring domains** | Perfil de enlaces |
| **Conversion Rate orgánica**   | Conversiones desde SEO |
| **Indexed pages**              | Páginas en el índice |
| **Crawl stats**                | Salud de rastreo |

#### ASO
| Métrica                        | Qué mide |
|--------------------------------|----------|
| **Impressions**                | Veces que se muestra la ficha |
| **Conversion Rate (CR)**       | Instalaciones / visitas a la ficha |
| **Keyword Rankings**           | Posición por palabra clave |
| **Organic Downloads**          | Instalaciones orgánicas |
| **Ratings & Review velocity**  | Cantidad y ritmo de reseñas |
| **Retention (D1, D7, D30)**    | Calidad de usuarios adquiridos |
| **Brand vs Generic traffic**   | Búsquedas de marca vs genéricas |
| **Visibility Score**           | Indicadores de visibilidad en tienda |
